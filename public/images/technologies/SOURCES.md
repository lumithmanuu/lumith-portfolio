# Technology logos

These local SVG files are used beside their visible technology names in the Tech Stack section. Product names and marks belong to their respective owners.

- All icons except Seaborn and Joblib: [Devicon](https://github.com/devicons/devicon), downloaded from `icons/{name}/{name}-original.svg` on the `master` branch. The upstream license is included in `DEVICON-LICENSE.txt`.
- Joblib: [official Joblib logo](https://github.com/joblib/joblib/blob/main/doc/_static/joblib_logo.svg).
- Seaborn: [official Seaborn logo](https://seaborn.pydata.org/_static/logo-mark-lightbg.svg).

Retrieved on 2026-09-26. No runtime icon service or additional package is required.
